# Elemental Rivals

Play: https://roodeexx.github.io/elemental-rivals/

A browser prototype for testing spells with friends: create a room, send the 4-letter code,
farm mobs, then fight in the arena. Up to 10 players.

This repo holds only the built game page (served by GitHub Pages) and the room relay in
`relay/` (run on Render's free plan, set up by `render.yaml`). The free relay sleeps when
nobody plays and takes up to a minute to wake.
